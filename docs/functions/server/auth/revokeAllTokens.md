# revokeAllTokens

## Назначение
Отзывает все выданные токены: увеличивает версию в базе. Токены с прежней версией перестают проходить проверку.

## Где объявлено
`server/src/services/auth.js:L30-37#revokeAllTokens`

## Вход и выход
- Вход: нет.
- Выход: `Promise<void>`. Побочный эффект: новая версия в базе и в кэше.

## Алгоритм
1. Атомарно увеличивает `tokenVersion` на 1: `server/src/services/auth.js:L33@$inc: { tokenVersion: 1 }`.
2. Создаёт документ, если его не было (`upsert: true`).
3. Обновляет кэш значением из ответа базы, чтобы текущий процесс сразу отверг старые токены: `server/src/services/auth.js:L24@cachedVersion = doc.tokenVersion;`.

## Ошибки и граничные случаи
- Отзыв глобальный: сбрасываются все токены, включая токен воркера и токен Mini App. Это выбор по умолчанию: частичный отзыв потребовал бы хранить список токенов.
- После отзыва нужно войти заново везде. Именно это описано в подтверждении в интерфейсе: `client/src/App.jsx:L27-131#App`.
