# acceptTask

## Назначение
Принимает результат проверки: задача переходит из «На проверке» в «Принято». Слияния в `main` не делает, это решение отложено (см. бэклог).

## Где объявлено
`server/src/services/runs.js:L46-53#acceptTask`

## Вход и выход
- Вход: `task`.
- Выход: `{ task }` или `{ error }`, если задача не на проверке.

## Алгоритм
1. Проверяет статус: `server/src/services/runs.js:L48@Принять можно только задачу на проверке`.
2. Ставит статус `done` и сохраняет: `server/src/services/runs.js:L50@task.status = 'done';`.

## Ошибки и граничные случаи
- Переход задаётся тем же правилом, что и в таблице переходов (`review → done`). Функция проверяет статус отдельно, потому что вызывается не через маршрут PATCH, а из бота.
- Ветка задачи остаётся в origin, и её можно удалить вручную.
